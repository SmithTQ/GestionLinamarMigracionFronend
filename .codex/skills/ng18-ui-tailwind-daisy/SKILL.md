# Ng18 UI with Tailwind + DaisyUI

## Workflow

1. Define layout structure with Tailwind utility classes.
2. Use DaisyUI components (`card`, `btn`, `alert`, `input`, `badge`).
3. Apply a custom DaisyUI theme for brand colors.
4. Ensure mobile-first spacing and typography.
5. Add subtle gradients and depth to avoid flat layouts.

## Guardrails

- Avoid default system fonts; prefer the project font.
- Keep color usage consistent with the theme.
- Use semantic HTML with accessible labels.

## Files

- `src/styles.css`
- `tailwind.config.js`
- `src/app/**/component.html`
